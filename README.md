# 电子课表

适用于学校希沃交互式白板（Windows 10 x64）的电子课表。一条半透明课程横条贴在屏幕顶端居中，显示日期、当前课程及其进度、下一节课和时钟，后台静默运行，不占任务栏。

## 功能

- 顶部横条：569×40 像素，紧贴屏幕上缘，圆角半透明，不遮挡授课内容
- 今日日期与星期、秒级时钟
- 当前课程加粗显示，下方细进度条显示本节课进度
- 下一节课提示
- 点击横条展开当天完整课表（带下滑动画），再次点击收起；鼠标悬停时横条变亮
- 当天有临时调课时，日期旁出现黄色「调」角标
- 上下课铃声提醒：预备铃（默认提前 2 分钟）、上课铃、下课铃，横条同步显示暖色横幅
- 全屏隐藏时铃声照常播放，放课件时也不会漏铃
- 后台静默运行，只在托盘区留一个图标；右键可编辑课表、开关提醒、开机自启、退出
- 全屏授课软件（幻灯片放映、全屏视频、浏览器 F11，以及铺满屏幕但保留任务栏的窗口）自动隐藏，结束后自动恢复；普通最大化窗口和桌面获得焦点时都不会误触发
- 显示时不抢授课软件焦点
- 内置可视化课表编辑器，支持从 Excel 导入、按日期临时调课
- 单文件，无需安装 .NET

界面形态参考了 [ClassIsland](https://github.com/ClassIsland/ClassIsland) 的主界面。

## 打开方式

双击 `电子课表.exe` 即可，程序会最小化地贴在屏幕顶端。关闭或退出要通过托盘图标（右下角绿色「课」字圆形图标）右键菜单。

托盘菜单：

| 菜单项 | 作用 |
| --- | --- |
| 编辑课表… | 打开课表编辑器 |
| 展开/收起课表 | 展开或收起当天完整课表 |
| 上下课提醒 | 打勾即可开启或关闭铃声（改动会写回 `schedule.json`） |
| 试听铃声 | 播放一次上课铃，确认音量合适 |
| 开机自动启动 | 勾选后写入当前用户的启动项，无需管理员权限 |
| 重新载入课表 | 手动改完 `schedule.json` 后重新读取 |
| 退出 | 关闭程序 |

命令行参数：

```bash
电子课表.exe --edit            # 直接打开课表设置
电子课表.exe 课表.xlsx          # 打开设置并导入 Excel
```

把 .xlsx 文件拖到 `电子课表.exe` 上，效果同第二行。

## 做课表

托盘右键 →「编辑课表…」，或者带 `--edit` 启动。

窗口分三块：左边选星期，中间一节课一行，右下角是「保存」。

1. **左边选星期**：周一到周日，每项后面显示那天有多少节课。
2. **中间填课**：每行代表一节课
   - 左边两个框是上课、下课时间，点上下箭头调整
   - 中间输入课程名，例如「语文」
   - 点「删除」移除这节课
3. **添加**：点左下角「＋ 添加一节课」，会在最后一节课之后自动排 10 分钟后的时间。
4. **保存**：点右下角「保存」，只保存当前这一天，其它天不受影响；状态栏会提示已保存。

改完不用关程序，横条会在下次点击时读到最新数据；想立刻刷新也可以托盘右键「重新载入课表」。

### 临时调课

点「临时调课…」打开调课窗口：选一个日期，只改那天要变的课。

- 把某节课写成新的课程名 = 那天换课
- 把某节课清空 = 那天取消这节
- 改过的格子显示为黄色，点「写回原课表」可以一键还原
- 只影响选中的那一天，正式课表不受影响；横条上会出现「调」角标提醒

### 从 Excel 导入

点「从 Excel 导入…」，或把文件拖到 exe 上。要求：

- 文件是 `.xlsx`（不支持老的 `.xls`）
- 有一行表头包含「周一」…「周日」（或「星期一」…「星期日」），至少三个
- 每个课程行的左侧单元格里有时间，格式 `08:00-08:45`（也接受 `08:00~08:45`、`8:00至8:45`）

导入会替换整份课表，界面上会先确认一次。

### 用 Excel 模板快速录入

主目录的 [课表模板.xlsx](课表模板.xlsx) 已经按「早读 1 节 + 上午 5 节 + 下午 4 节 + 晚自习 4 节」排好了 14 个时间段，直接在上面填课程名即可：

1. 打开 `课表模板.xlsx`，第一个工作表是「课表」，第二个是「填写说明」。
2. B 列到 H 列分别是周一到周日，在格子里填课程名，没有课就留空。
3. 时间在第一列，格式必须是 `08:00-08:45` 这种；和学校作息不一样就直接改。
4. 周一那列已填了示例课程，导入前请清掉或改成自己的。
5. 填完保存，然后把它拖到 `电子课表.exe` 上，或在编辑器里点「从 Excel 导入…」。
6. 导入后检查一遍，点「保存」。

要增删节次就在表里加行或删行，时间跟着改就行。

## 配置文件

程序读取与 exe 同目录的 `schedule.json`，编辑器保存时也写这里。

```json
{
  "title": "电子课表",
  "appearance": { "opacity": 0.9, "animateExpand": true },
  "reminders": { "enabled": true, "prepareMinutes": 2, "prepare": true, "start": true, "end": true },
  "lessons": [
    { "day": 1, "start": "08:00", "end": "08:45", "name": "语文" },
    { "day": 2, "start": "15:50", "end": "16:35", "name": "班会" }
  ],
  "overrides": [
    { "day": 5, "start": "08:00", "end": "08:45", "name": "临时英语", "date": "2026-10-30" },
    { "day": 5, "start": "08:55", "end": "09:40", "name": "", "date": "2026-10-30" }
  ]
}
```

| 字段 | 说明 |
| --- | --- |
| `title` | 窗口标题 / 托盘提示，可省略 |
| `appearance.opacity` | 横条不透明度，0.3 ~ 1.0，默认 0.9 |
| `appearance.animateExpand` | 展开/收起是否播放动画，默认 true |
| `reminders.enabled` | 上下课提醒总开关 |
| `reminders.prepareMinutes` | 预备铃提前几分钟，填 0 表示不打预备铃 |
| `reminders.prepare` / `start` / `end` | 分别控制预备铃 / 上课铃 / 下课铃 |
| `reminders.bannerSeconds` | 提醒横幅在横条上停留的秒数，默认 8 |
| `lessons[].day` | 星期，1 = 周一 … 7 = 周日 |
| `lessons[].start` / `end` | 24 小时制 `HH:mm`；`end` 时刻不计入本节课 |
| `overrides[].date` | 调课生效的具体日期 `yyyy-MM-dd` |
| `overrides[].name` | 当天空字符串表示取消该节 |


## 构建

项目使用 .NET 8 WinForms，没有任何第三方依赖，xlsx 由内置的最小读取器解析。

**轻量版（当前仓库里的 exe，约 190 KB）**：依赖机器上已安装的 .NET 8 桌面运行时。

```bash
dotnet publish ElectronicSchedule.csproj -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=false
```

**免安装版（约 68 MB）**：把运行时一起打包，拷到任何 Windows 10 x64 都能直接跑。

```bash
dotnet publish ElectronicSchedule.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true
```

两种产物都会在输出目录生成 `电子课表.exe` 和 `schedule.json`。WinForms 不支持 .NET 的裁剪（trimming），所以免安装版的体积就是运行时本身的大小。

仓库自带 GitHub Actions 工作流（`.github/workflows/build.yml`）：推送 `main` 后会在 Actions 页面生成两种版本的 artifact；推送 `v*` 标签（例如 `v0.2.0`）会自动创建 GitHub Release，两个 exe、`schedule.json` 和 `课表模板.xlsx` 一起附在 Release 里。

## 部署

把 `电子课表.exe` 和 `schedule.json` 放在同一目录即可。

仓库里的轻量版要求目标机器装有 [.NET 8 桌面运行时](https://dotnet.microsoft.com/download/dotnet/8.0)（约 55 MB，装一次即可）。如果白板机器不方便装运行时，改用上面命令生成免安装版，只是文件夹会变成 68 MB 左右。

程序为单实例，重复双击不会启动第二个。异常记录在 `%LOCALAPPDATA%\ElectronicSchedule\error.log`。

## 参赛材料

`docs/` 目录下是参加科技创新大赛用的材料：

| 文件 | 说明 |
| --- | --- |
| `docs/研究报告.md` | 研究报告全文（可编辑源稿） |
| `docs/研究报告.docx` | 同一份报告转成的 Word，用于提交知网查重 |

研究报告里标有【待填】或 ______ 的地方，是需要你补充的真实数据（试用班级、周数、师生反馈等），提交前务必替换，不要保留占位符。

查重前请按组委会要求重命名文档，格式为「篇名_作者.docx」，例如 `面向教室交互白板的轻量级悬浮课表系统设计与实现_张三.docx`，否则知网无法自动提取作者信息。

查新报告、诚信承诺书、申报书需要使用市赛组委会提供的样表填写，样表结构见 `C:\Users\Administrator\Desktop\2026汉中市创赛模板`。
